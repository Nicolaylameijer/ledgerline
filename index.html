Ledgerline Personal

A private, read only tool for one person's own money. Last updated October 2026.

What this is

Ledgerline Personal is a small program that runs on one person's own computer. It reads that person's own account balances and transactions so they can keep a personal budget and see their own net worth. It is not offered to the public and has no other users.

What data it uses

Account names, balances, transactions and, for investment accounts, holdings. It asks only for read access. It cannot move money, make payments, transfer funds or place trades.

Where the data lives

On the owner's computer only. Access keys are kept in the computer's secure keychain, and the data is kept in a private local database. Nothing is uploaded to a server we run, and nothing is shared with, or sold to, anyone.

Connections to banks

Banks are connected through Plaid. Sign in happens inside the bank's own screens, so this tool never sees bank passwords. The owner can disconnect a bank at any time from Plaid Portal (my.plaid.com) or by contacting the bank.

Retention and deletion

Data stays on the owner's computer until the owner deletes it. Disconnecting a bank stops all further collection.
